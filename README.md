# shortmaker

숏폼 영상을 만들어 본인의 YouTube 채널에 올리는 개인용 도구입니다.

대본을 붙여넣으면 장면으로 나누고, 나레이션 음성을 만들고, 장면마다 쓸
이미지와 영상을 모아 9:16 세로 영상 한 편으로 이어 붙입니다. 완성한 영상은
만든 사람의 채널에 바로 올립니다.

사용자의 컴퓨터에서만 실행됩니다. 운영하는 서버가 없습니다.

## 하는 일

- 대본을 장면과 컷으로 나누고 자막 시각을 맞춥니다
- 나레이션 음성을 만들고, 영어와 숫자를 한국어로 어떻게 읽을지 맞춥니다
- 장면마다 쓸 이미지·영상 프롬프트를 만듭니다
- 제목과 자막을 얹어 9:16 영상으로 이어 붙입니다
- 완성본을 본인 YouTube 채널에 올립니다

## YouTube 권한

영상 업로드에 필요한 `youtube.upload` 하나만 요청합니다. 시청 기록, 구독자
명단, 다른 영상을 읽지 않습니다.

자세한 것은 [개인정보처리방침](PRIVACY.md)과 [이용약관](TERMS.md)에 적혀 있습니다.
